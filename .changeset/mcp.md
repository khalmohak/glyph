New package: `@glyphui/mcp`, an MCP server that gives Claude Code, Cursor, VS Code, Windsurf and Claude Desktop Glyph's components, props, examples, guides, setup and theming, so agents use the real API instead of guessing. Run it with `npx -y @glyphui/mcp`; setup for each editor is in the new [Use with AI](https://glyphui.xyz/docs/ai) guide. The data is generated from the docs at build time and ships in the package, so answers match the installed Glyph version and need no network.
